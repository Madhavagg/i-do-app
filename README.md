## 🚀 Quick Start

### 1. Install Claude Code
```bash
npm install -g @anthropic-ai/claude-code
claude  # Follow prompts to log in
```

### 2. Set Up Your Workspace
Open two windows side-by-side:

```
┌─────────────────────────┬─────────────────────────┐
│   Terminal              │      Cursor             │
│                         │                         │
│   $ cd ai-todo-app      │   [Watch files change   │
│   $ claude              │    as Claude builds]    │
│                         │                         │
│   You: Set up a new     │                         │
│   Next.js project...    │                         │
└─────────────────────────┴─────────────────────────┘
```

### 3. Start Building
Open `CLAUDE-CODE-GUIDE.md` and follow the conversation prompts!

## 🎯 What You'll Build

**Phase 1:** Beautiful to-do app with add, edit, delete, filter, priorities

**Phase 2:** Natural language input ("Buy groceries tomorrow" → smart task)

**Phase 3:** User accounts, database, multi-device sync

**Phase 4:** AI creates calendar events, sends reminders

**Phase 5:** AI plans your day, notices patterns, gives insights

You're building **two things**:
